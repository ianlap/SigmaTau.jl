The explorer

The explorer is the package with a window. It opens a record, checks it and shows the deviations, the spectra, the dynamic deviation and the time error in holdover of one clock or of several, with every setting on screen. It also simulates clocks from a noise model, forms a time scale from a group of clocks and follows a measurement while it runs.

Every result it shows is computed by the sigmatau program, which runs the code of the Julia functions. The report of an analysis lists the command lines that repeat it.

The explorer comes as a desktop app and as pages that a script serves to a browser. Both show the same pages, and Install and run covers the two.

A first analysis

The explorer starts with a simulated record of 16384 phase samples at 1 s and its analysis, so that every page has something to show before a file is open.

  1. Open the record. On the Data page press Open a file…, or drop a file anywhere in the window. The import dialog shows the top of the file and asks what each column holds, whether the readings are phase or fractional frequency, and in which unit.
  2. Check it. The record check lists the samples, the span, the gaps, the points past 5σ and the frequency drift, beside a plot of the phase. Drift removal, gap filling and outlier removal are set there.
  3. Choose the estimators. + Add estimator in the side panel opens the list. The τ grid, the confidence level, the bias correction and the noise type are under Options.
  4. Run the analysis with Run analysis or F5.
  5. Read the results on the Stability, Spectrum, Dynamic, Holdover and Steering pages.
  6. Keep them. The File menu saves the plot, the numbers, a report and the whole session.

When results are computed

A change to the record, to the estimators or to the options does not start an analysis, and neither does a file that has just been opened. The Run button and the status bar turn amber, and the Stability and Spectrum pages keep the results of the last run until Run analysis is pressed again. A run can be canceled, and the results from before then stay on screen.

The explorer runs the analysis by itself in five cases: at start, on its simulated record; when the reference clock changes and there are results; when a session is opened; when the readings of a live measurement are loaded; and after each change to a noise model built by hand.
