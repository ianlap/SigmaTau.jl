SigmaTau.jl

Time-and-frequency stability analysis in Julia: the Allan, modified Allan, Hadamard, modified Hadamard and total deviation families, Thêo1/ThêoH, MTIE, TIE rms and PDEV, with per-τ noise identification and χ² confidence intervals computed in the same call. The core estimators are validated against Stable32 and allantools; see Validation.

Install

pkg> add https://github.com/ianlap/SigmaTau.jl

Julia 1.11 or later.

First run

using SigmaTau, Random
Random.seed!(42)

# White FM at σ_y(1 s) = 1e-12 plus random-walk FM, 8192 samples at τ₀ = 1 s
p = noise_gen(PhaseData, 8192, 1.0; sigma1 = Dict(0 => 1e-12, -2 => 3e-14))

r = adev(p)                      # octave τ grid, χ² CI, per-τ noise ID

Reading a file, choosing a τ grid and plotting:

p = read_phase("clock.DAT"; time_col=0, value_col=1, tau0=1.0)
adev(p, [1, 2, 4, 8, 16, 32])    # explicit averaging factors
adev(p, Decade)                  # decade-spaced grid

using Plots
plot(adev(p))                    # log-log σ(τ) with CI error bars
plot(stability(p))               # overlay a suite

Stable32 run types

Stable32SigmaTau
OADEV, MDEV, TDEVadev, mdev, tdev (the Allan estimators are always overlapping)
OHDEVhdev
TOTDEV, MTOT, TTOT, HTOTtotdev, mtotdev, ttotdev, htotdev
Thêo1 / ThêoBR, ThêoHtheo1 (correct_bias=false gives raw Thêo1), theoh
MTIE, TIE rmsmtie, tierms
Dynamic stabilitydadev, dhdev
Three-cornered hatnch
Noise generationnoise_gen
Drift / outlier / gap toolsdetrend, remove_outliers, fillgaps

Not in Stable32: mhdev, htdev, mhtotdev, pdev, StreamingStability.

References

Definitions follow NIST SP1065 (Riley, Jul 2008) and IEEE Std 1139-2022 (IEEE Ultrasonics and Society, 2022); confidence intervals use the Greenhall–Riley EDF algorithm (Greenhall and Riley, 2003).
