Records and results

A record goes in and a result comes out. Every estimator takes a PhaseData or a FrequencyData record, which carries the sample interval with the samples, and returns a StabilityResult. Conventions defines the quantities and their units.

Records

SigmaTau.AbstractTimingData — Type
AbstractTimingData

Supertype of the data records PhaseData and FrequencyData.

source
SigmaTau.PhaseData — Type
PhaseData(x, tau0=1.0; source="user", start=NaN)

Phase samples $x(t)$ in seconds at the uniform sample interval tau0: the time deviation of a clock from its reference (IEEE Std 1139-2022, 3.1). Every estimator takes this record, so the sample interval travels with the data.

x can be any real vector, such as a view, a range or integers, and is copied to a Vector of floats. NaN marks a missing sample (see fillgaps). A record holds at least two samples, and length(data) returns their number.

read_phase builds a record from a file, and PhaseData(f) converts a FrequencyData record to phase.

Examples

julia> using SigmaTau

julia> PhaseData([0.0, 1.5e-9, 2.9e-9, 4.6e-9], 10.0)
PhaseData{Float64}(4 samples, τ₀=10 s)

Fields

  • x::Vector{T} where T<:AbstractFloat: Phase samples, in seconds.

  • tau0::Float64: Sample interval τ₀, in seconds.

  • source::String: Origin of the record: "user" when constructed directly, the file path when read by read_phase. detrend, fillgaps and remove_outliers keep it, and save writes it to the file header.

  • start::Float64: UTC time of the first sample, in seconds since 2000-01-01T00:00Z, or NaN when unknown. The readers set it from ISO 8601 or MJD timestamps and from a # start: header line; start_time returns it as a DateTime.

source
SigmaTau.FrequencyData — Type
FrequencyData(y, tau0=1.0; source="user", start=NaN)

Fractional-frequency samples $y(t) = (ν(t) - ν_0)/ν_0$, dimensionless, at the uniform sample interval tau0 (IEEE Std 1139-2022, 3.1). Each sample is taken as the average over its interval, with no dead time. Every estimator accepts the record and integrates it to phase before the analysis.

Like PhaseData, the record takes any real vector, marks a missing sample with NaN, holds at least two samples and supports length.

read_frequency builds a record from a file, and FrequencyData(p) converts a PhaseData record to frequency. The two conversions are described below.

Examples

julia> using SigmaTau

julia> FrequencyData([1.2e-11, -0.4e-11, 0.7e-11], 10.0)
FrequencyData{Float64}(3 samples, τ₀=10 s)

Fields

  • y::Vector{T} where T<:AbstractFloat: Fractional-frequency samples, dimensionless.

  • tau0::Float64: Sample interval τ₀, in seconds.

  • source::String: Origin of the record: "user" when constructed directly, the file path when read by read_frequency. detrend, fillgaps and remove_outliers keep it, and save writes it to the file header.

  • start::Float64: UTC time of the first sample, in seconds since 2000-01-01T00:00Z, or NaN when unknown. The readers set it from ISO 8601 or MJD timestamps and from a # start: header line; start_time returns it as a DateTime.

The other result types are documented with the functions that return them: DriftFit, PowerLawFit, NoiseFit, CrossStabilityResult, CrossSpectralResult, KalmanResult, HoldoverResult and TimescaleResult.

SigmaTau.StabilityResult — Type
StabilityResult

Result of every stability estimator: one deviation per averaging time, with the noise type, the equivalent degrees of freedom and the confidence interval when the estimator was called with ci=true.

ci and edf are empty for a call with ci=false, and always for mtie and tierms. noise_type is empty too, unless a bias correction needed the noise type. neff is always filled. The interval at point i runs from r.ci[i].lo to r.ci[i].hi; ci_lower and ci_upper return the limits as vectors. Displaying a result prints it as a table.

Fields

  • deviation_type::Symbol: Estimator that produced the result, such as :adev.

  • tau::Vector{Float64}: Averaging times τ, in seconds.

  • dev::Vector{Float64}: Deviation at each τ: dimensionless for the σ_y estimators, in seconds for tdev, htdev, ttotdev, mtie and tierms.

  • noise_type::Vector{Symbol}: Noise type at each τ, identified or stated: :WHPM, :FLPM, :WHFM, :FLFM, :RWFM, :FWFM or :RRFM.

  • ci::Vector{@NamedTuple{lo::Float64, hi::Float64}}: Confidence interval (lo, hi) at each τ.

  • edf::Vector{Float64}: Equivalent degrees of freedom at each τ.

  • neff::Vector{Int64}: Number of terms averaged at each τ; 0 where the deviation is NaN.

  • tau0::Float64: Sample interval τ₀ of the record, in seconds; NaN if unknown.

  • n::Int64: Number of phase samples in the record; 0 if unknown.

  • confidence::Float64: Confidence level of ci; NaN when there is no interval.

source

ci_lower(r::StabilityResult) → Vector{Float64}

ci_upper(r::StabilityResult) → Vector{Float64}

Upper confidence limits of r, one per averaging time; empty when the result carries no interval.

SigmaTau.StabilitySuite — Type
StabilitySuite

The results of one stability call: a StabilityResult per estimator, in the order requested, with the record and grid settings that produced them.

suite[:adev] returns a result by estimator name and suite[1] by position. The suite iterates in order and supports keys, haskey, length and pairs. save writes it to one file.

Fields

  • results::Vector{StabilityResult}: One result per estimator, in the order requested.

  • data_kind::Symbol: Kind of the input record: :phase or :frequency.

  • tau0::Float64: Sample interval τ₀, in seconds.

  • n::Int64: Number of phase samples in the record.

  • confidence::Float64: Confidence level of the intervals; NaN for ci=false.

  • tau_mode::Symbol: Grid the suite was run on: the TauMode name, such as :Octave, or :explicit.

source
SigmaTau.SpectralResult — Type
SpectralResult

Result of the spectral-density estimates psd_y, psd_x and ssb_phase_noise: the one-sided frequency grid, the estimated density and the Welch settings that produced it.

Fields

  • spectral_type::Symbol: Quantity estimated: :Sy for $S_y(f)$, :Sx for $S_x(f)$ or :L for $ℒ(f)$.

  • freq::Vector{Float64}: Fourier frequencies $f$, in Hz.

  • psd::Vector{Float64}: Spectral density at each $f$, in the unit named by units.

  • units::Symbol: Unit of psd: :per_Hz ($S_y$, 1/Hz), :s2_per_Hz ($S_x$, s²/Hz) or :dBc_per_Hz ($ℒ$).

  • nperseg::Int64: Welch segment length, in samples.

  • noverlap::Int64: Overlap of successive segments, in samples.

  • taper::Symbol: Taper applied to each segment: :hann, :hamming or :rectangular.

source
SigmaTau.DynamicStabilityResult — Type
DynamicStabilityResult

Result of the dynamic deviations dadev and dhdev: a map $σ_y(t, τ)$ of the deviation computed inside a window of window phase samples that slides along the record.

Row i of dev is the window centered at t[i], and column j the averaging time tau[j]. An entry is NaN where the window is too short for the averaging factor.

The result carries no noise type, EDF or interval. Galleani (2011) derives confidence surfaces for the dynamic Allan variance; they are not implemented here.

Fields

  • deviation_type::Symbol: Estimator that produced the result: :dadev or :dhdev.

  • t::Vector{Float64}: Center time of each window, in seconds from the first sample; one per row of dev.

  • tau::Vector{Float64}: Averaging times τ, in seconds; one per column of dev.

  • dev::Matrix{Float64}: Deviation map, length(t) by length(tau).

  • window::Int64: Window length, in samples.

  • tau0::Float64: Sample interval τ₀, in seconds.

source

Results as tables

With Tables.jl loaded, a StabilityResult and a StabilitySuite are row tables, with one row for each deviation and averaging time:

ColumnTypeContent
deviation_typeSymbolThe estimator, such as :adev
tauFloat64The averaging time, in seconds
devFloat64The deviation
noise_typeSymbol or missingThe noise type
ci_lower, ci_upperFloat64 or missingThe confidence limits
edfFloat64 or missingThe equivalent degrees of freedom
neffIntThe number of terms averaged

A column reads missing where the result holds no value, as the limits and the EDF do after a call with ci=false.

using SigmaTau, Tables

rows = Tables.rows(adev(data))
cols = Tables.columntable(stability(data; devs=(:adev, :mdev)))

Tables is a weak dependency. Its methods load with it, and using SigmaTau alone loads no table package. Plotting and tables hands a result to DataFrames and CSV.
