SigmaTau.jl

SigmaTau.jl measures the stability of clocks and oscillators from records of phase or fractional frequency. It computes the Allan and Hadamard deviations with their modified, time and total forms, Thêo1, ThêoH and the parabolic deviation, and at each averaging time it identifies the noise type and gives a χ² confidence interval. Around them it has spectra and phase noise, MTIE with telecom masks, tools to prepare a record, a clock model with a Kalman filter, steering loops, and time scales formed from several clocks.

using SigmaTau, Random

# 8192 phase samples at 1 s: white FM of 1e-12 at 1 s, and random-walk FM
p = noise_gen(PhaseData, 8192, 1.0; sigma1 = Dict(0 => 1e-12, -2 => 3e-14),
              rng = Xoshiro(5))
adev(p)

All four run the same code. Python calls the Julia functions themselves. The compiled program, which the explorer also runs, is tested to give their results within a relative difference of $10^{-12}$.

Install

pkg> add SigmaTau

installs the latest registered release, and pkg> add https://github.com/ianlap/SigmaTau.jl the repository as it stands. The package needs Julia 1.11 or later. Plots is optional: loading it turns on the plot recipes.

A release carries the explorer and the command-line program as programs that need no Julia. Their pages say how to install them, and how to run or build them from the repository.

This documentation

  • Tutorials work through an analysis from start to finish: a first result, a drifting clock, a file of your own, three clocks compared, an ensemble.
  • How-to guides each answer one question: which estimator to use, how to prepare a record, how to plot, how to run the command line or Python.
  • The explorer is the manual of the graphical program.
  • Background explains what the numbers rest on: the conventions, the noise types and how they are identified, confidence intervals and bias factors, and the evidence that the results are right.
  • Reference documents every exported function and type.

Sources

The definitions follow the NIST handbook of frequency stability analysis (Riley, 2008), cited as SP1065 throughout, and IEEE Std 1139-2022. Confidence intervals use the equivalent degrees of freedom of Greenhall and Riley (2003). Each page cites what it states, with the section or equation, and the Bibliography lists every source.

Where the package departs from a source, or goes beyond one, the page that covers the subject says so and says what the choice rests on. Validation describes the evidence for the results, and Related software the programs they were compared with.
