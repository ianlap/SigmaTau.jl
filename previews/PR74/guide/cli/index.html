Command line

sigmatau-cli runs a SigmaTau analysis from the shell and prints one JSON document on standard output. It is the compiled analysis core behind the explorer, so it starts in about 30 ms with no Julia session, and any language that can run a program and parse JSON can use it.

Build

The program is compiled with juliac --trim; you need Julia 1.12 or newer and JuliaC (pkg> app add JuliaC):

julia --project=app/web/cli -e 'using Pkg; Pkg.instantiate()'
juliac --output-exe sigmatau-cli --bundle app/web/cli/build --trim=safe --experimental app/web/cli

The executable is app/web/cli/build/bin/sigmatau-cli. Without a build, julia --project=app/web/cli -m SigmaTauCLI [flags] runs the same code, paying Julia's start-up on each call.

Examples

# ADEV, MDEV, HDEV and MHDEV of a phase file, octave τ grid, 68.3 % intervals
sigmatau-cli --input clock.dat

# Frequency data with no time column, sampled every 10 s, at 95 %
sigmatau-cli --input freq.txt --kind frequency --time-col 0 --tau0 10 --confidence 0.95

# Clock in column 3 against the reference in column 4, values in ns
sigmatau-cli --input pair.csv --value-col 3 --reference-col 4 --scaling 1e-9

# Total estimators on a decade grid, with the spectrum and a dynamic ADEV map
sigmatau-cli --input clock.dat --devs totdev,mtotdev,htotdev --grid decade --spectrum --dynamic dadev

# A synthetic white FM + random-walk FM record, to try it out
sigmatau-cli --synth 8192 --seed 1

Output

On success the exit code is 0 and the output looks like this (arrays shortened):

{
  "sigmatau": "0.5.0",
  "record": { "n": 16384, "tau0": 1.0, "kind": "phase", "source": "clock.dat",
              "series": { "t": [0.0, 4.0, ...], "x": [0.0, 1.2e-12, ...] },
              "check": { "samples": 16384, "span_s": 16384.0, "gaps": 0, "outliers": 2,
                         "outlier_t": [...], "outlier_x": [...], "drift_per_day": 3.1e-14 } },
  "options": { "grid": "octave", "ci": true, "confidence": 0.683, "bias_correction": true },
  "results": [
    { "dev": "adev", "axis": "sigma_y", "tau": [1.0, 2.0, ...], "sigma": [...],
      "ci_lo": [...], "ci_hi": [...], "edf": [...], "noise": ["WHFM", ...], "neff": [...] }
  ],
  "spectrum": { "nperseg": 4096, "f": [...], "sy": [...], "sx": [...] },
  "dynamic": { "dev": "adev", "window": 2048, "step": 1024, "t": [...], "tau": [...],
               "map": [[...], ...] },
  "elapsed_ms": 41.7
}
  • results has one entry per estimator, in the order of --devs. axis is sigma_x (seconds) for tdev, htdev, ttotdev, mtie and tierms and sigma_y otherwise. ci_lo, ci_hi, edf and noise are empty with --no-ci.
  • check is the record check: NaN gaps, points past 5σ (at most 500 listed) and the linear frequency drift per day.
  • spectrum and dynamic appear only when asked for. The spectrum leaves out the DC bin and needs a record without gaps. In dynamic, t holds the window centres in seconds and map has one row per window, one column per τ.
  • Non-finite numbers are written as null.

On failure the exit code is 2 and the output is {"error": "message"}. Running with no arguments prints a usage line and exits with 1.

From Python

import json, subprocess

out = subprocess.run(
    ["sigmatau-cli", "--input", "clock.dat", "--devs", "adev,hdev"],
    capture_output=True, text=True,
)
doc = json.loads(out.stdout)
if out.returncode != 0:
    raise RuntimeError(doc["error"])
adev = doc["results"][0]
print(adev["tau"], adev["sigma"])
