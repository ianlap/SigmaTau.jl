Python

sigmatau is the Python package of this project. It is a wrapper, not a second implementation: each function calls the Julia function of the same name in a Julia runtime inside the Python process, through juliacall. The numbers are those of the Julia package, and this documentation applies to both.

Install

pip install sigmatau        # the latest release on PyPI
pip install -e python       # from a checkout of the repository, as it stands

The package needs Python 3.11 or later. From a checkout the install has to be an editable one (-e), because the package finds the Julia code by its path in the checkout. The first import sigmatau finds a Julia of version 1.11 or later, or installs one, creates a Julia environment inside the Python environment and precompiles the package, which takes a few minutes. Later imports take a few seconds.

Import sigmatau before juliacall. On import it asks juliacall to let Julia handle signals, so that Ctrl-C interrupts a long calculation, and to start Julia with all threads, for the total estimators. It cannot do either once juliacall is loaded, and warns. Leave Python's faulthandler off: it takes the signals that Julia's threads use among themselves for crashes.

A first analysis

import sigmatau as st

p = st.noise_gen(st.PhaseData, 4096, 1.0, sigma1={0: 1e-12}, rng=42)

r = st.adev(p)                    # octave spacing, noise type and intervals
r.tau, r.dev, r.noise_type, r.ci_lower, r.ci_upper, r.edf

r = st.adev(p, [1, 10, 100], confidence=0.95, noise="WHFM")

suite = st.stability(p, devs=("adev", "mdev", "hdev"))
suite["mdev"].dev

st.save("adev.tsv", r)            # st.load reads it back

A record of your own is st.PhaseData(x, tau0) or st.FrequencyData(y, tau0) from a NumPy array, or the result of st.read_phase, st.read_frequency or st.read_data on a file.

More of the package

st.deviation("mhtotdev", p)                 # any estimator by name
st.psd_y(p)                                 # spectrum of fractional frequency
st.drift_fit(p).rate                        # frequency drift, per day
st.mask_check(st.mtie(p), "G8262_opt1").passed

fit = st.powerlaw_fit(p)                    # power-law model of the noise
model = st.clock_model(fit)                 # flicker=True keeps flicker noise as states
kf = st.kalman_filter(p, model)             # phase and frequency estimates
gains = st.steering_gains(3600.0, p.tau0)   # a steering loop, time constant 1 h
st.steer(p, model, gains).steered           # the record as that loop would leave it

cc, truth = st.simulate_ensemble([model] * 4, 10_000, rng=1)
st.timescale(cc).weights                    # AT1 weights against time
