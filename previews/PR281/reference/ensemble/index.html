Clock ensembles

A timescale starts from several clocks read against one reference at the same instants: a counter with a channel per clock, or a switch that steps through them. ClockComparisons holds those readings, and simulate_ensemble makes a set with known true states, each clock from its own ClockModel, to check the algorithms against.

ms = [ClockModel(; tau0=1.0, q1=1e-24), ClockModel(; tau0=1.0, q1=4e-24, q2=1e-30)]
cc, truth = simulate_ensemble(ms, 86400)
adev(cc[2, 1])       # clock 2 − clock 1, free of the reference
SigmaTau.ClockComparisons — Type
ClockComparisons(x::Matrix, tau0; names, reference="")
ClockComparisons(records::Vector{<:PhaseData}; names, reference="")

Phase readings of several clocks against one reference, sampled together: column i of x is clock i minus the reference, in seconds, one row per sample, NaN where a reading is missing. The reference may be one of the clocks (a switch or counter measuring each against clock 1, whose column is then zero) or an outside one, named by reference.

comparisons[i] is clock i's record as PhaseData, and comparisons[i, j] the difference clock i − clock j, which no longer depends on the reference.

  • x::Matrix{Float64}: Phase of each clock against the reference (s), one column per clock.

  • tau0::Float64: Sample interval τ₀ in seconds.

  • names::Vector{String}: Clock names, one per column.

  • reference::String: What the clocks were read against.

SigmaTau.simulate_ensemble — Function
simulate_ensemble(models::Vector{ClockModel}, N; reference=1, rng=nothing)
    → (ClockComparisons, Array{Float64,3})

N samples of an ensemble whose clock i follows models[i], read against clock reference (or, with reference = 0, against a perfect outside reference). Each reading carries its clock's white PM R and flicker PM. Returns the comparisons and the true states, truth[k, s, i] for sample k, state s and clock i (phase, frequency, and drift for a model with drift; zero beyond a clock's own states). The frequency includes the Markov states of a model with flicker FM. The models must share one τ₀.

SigmaTau.clock_models — Function
clock_models(cc::ClockComparisons; alphas=[2, 1, 0, -2], flicker=false) → Vector{ClockModel}

One ClockModel per clock, fitted from the comparisons alone, for the Kalman timescales (:greenhall, :jones_tryon), which need one. Needs three or more clocks: each clock's Allan deviation comes from the Groslambert covariance of the clock differences (groslambert), so the reference and the other clocks' noise drop out, and the power-law fit of powerlaw_fit on that curve, with the components alphas (white and flicker PM, white FM and random-walk FM by default), gives the model by clock_model, which folds the flicker PM into R. Fitted without its own term, flicker PM in the readings would pass for white FM and inflate q1. With flicker = true flicker FM joins the fit and each model carries its flicker FM and flicker PM as Markov states where they are needed (see ClockModel); the levels at the longest τ of a short record are then poorly separated, so check them against the curve. A clock whose curve the fit cannot use (too few positive points) throws.

Timescales

timescale averages the clocks' predicted phases into one scale. :ewfa gives every clock the same weight (Kettering's equal-weights frequency averaging (Kettering, 2023)), the baseline any weighting has to beat. :at1 is the NIST algorithm as Weiss & Weissert describe it (Weiss and Weissert, 1991): it learns each clock's prediction-error variance and weights by its inverse, which on clocks of steady noise converges to the optimal inverse-variance weights. The equation numbers in the docstring of timescale are the paper's. Three choices are the paper's and can be swapped: the bias term K that makes up for each clock being part of the scale (bias=:paper, or the exact bias=:exact), no cap on the weights (wmax), and no outlier test (outlier). Each clock's frequency constant comes from its own τ_min, which tau_min sets and which is otherwise read from the record. The paper leaves its starting values open, so these are this package's choices: the τ_min estimate, the starting variance τ²σ_y²(τ) taken from the record's first part, each clock's starting frequency (its fitted slope), and a variance memory of 20 days (memory) capped at a quarter of the record. :at2 keeps AT1's weights and replaces each clock's frequency filter by a Kalman update that carries a frequency variance, which adapts as the clock's prediction error does; in steady state it is AT1's filter, so the scales are close. steps=:best or :real adds the paper's frequency-step detection (eqs 19–22): a clock whose frequency jumps is left out for τ_min, while its new frequency is learned, and the scale rerun from the step; the threshold's units are corrected from the printed equation (see the docstring), and off by default. timescale_phase returns the scale against the reference, for the usual stability analysis.

r = timescale(cc; algorithm=:at1)
r.weights[end, :]                     # each clock's weight now
adev(timescale_phase(r))              # the scale's stability

AT1's weights are optimal for the interval between readings, since that is what each clock's prediction error measures; at much longer averaging times, with clocks whose long-term behaviour differs from their short-term, the scale can be worse than the best clock.

:greenhall is Greenhall's Kalman timescale. One Kalman filter tracks every clock's phase and frequency from the clock models; after each update the phase part of its covariance is reduced about a weighted mean of the corrected clocks, which keeps the frequency estimates and makes each step of the scale as small as it can be. Unlike AT1 it needs a model per clock, and it uses each clock's reading noise R. At R = 0 it is the reduced Kalman timescale of the 2003 paper; at R > 0 the filter is IEMx (2006). With reading noise the corrected clocks no longer agree and the implicit ensemble mean cannot be observed, so the scale is read at one clock, pivot (default 1): its reading less its estimated offset, which carries only that clock's reading noise. The realized scale carries that clock's reading noise as white PM, so at R > 0 it is not quieter than a weighted readout (with three equal clocks, √3 noisier at short τ). Pivots agree exactly at R = 0. While the pivot has no reading the first clock read stands in, and a pivot that starts late steps the scale at its first reading.

timescale(cc; algorithm=:greenhall, models=ms)

In simulation the scale's own stability is that of the implicit ensemble mean Σ aᵢ (xᵢ − x̂ᵢ), the weighted mean of the corrected clocks: each clock's true phase less the filter's estimate of it, r.xhat (implicit_mean). adev(timescale_phase(r)) adds the pivot clock's reading noise to it at short τ; at R = 0, with every clock read, the readout is the mean with its sign reversed.

:jones_tryon is the same filter without the covariance reduction, the natural Jones–Tryon scale (Jones and Tryon, 1983): a clock's reading less its estimated phase. It has the same frequency estimates and, with noiseless readings, the same scale at every clock, but it is slightly noisier at short τ (about 4% at τ = 1 on four white-FM clocks over ten seeds; single records up to 40% higher), which the reduction removes. Its reported weights are NaN. R is each clock's reading noise against the reference, so differences share the reference's noise; JT83 takes independent errors in each difference. JT83's error detection, step corrections and drift state are not included.

:stein is Stein's Kalman timescale (Stein, 2003), the KAS-2 algorithm (Levine, 2012; Erickson et al., 2011). Every clock is differenced against the pivot and each difference has a Kalman filter; the pivot's own shocks follow from the constraint that the weighted shocks of all clocks sum to zero, with separate weights for the phase, frequency and aging, inversely proportional to the variance of the matching noise. wmax caps the weights as in KAS-2.

timescale(cc; algorithm=:stein, models=ms, wmax=0.5)
SigmaTau.timescale — Function
timescale(cc::ClockComparisons; algorithm=:at1, …) → TimescaleResult

Form a timescale from the clocks in cc. At each sample every clock's phase against the scale is predicted from the last one and its estimated frequency, and the scale is placed so that the weighted prediction errors sum to zero. A clock without a reading keeps its prediction and drops out of the average for that sample; a clock joins at its first reading. Each clock's frequency starts at its least-squares slope over the first 10 % of the record, less the mean slope.

  • :ewfa, equal-weights frequency averaging, section 3.1 of (Kettering, 2023): every clock weighs the same, and the scale's frequency is the mean of the clocks' frequency steps over each interval, so with every clock read at every sample the scale is the plain mean of the clocks' phases. Gaps are not in the thesis: here a clock without a reading keeps its prediction (its last frequency step carried on) and drops out of the average for that sample, so the scale does not jump when a clock drops out, as the plain mean would.

  • :at1, the NIST scale as Weiss & Weissert describe it (Weiss and Weissert, 1991) (equation numbers are the paper's): weights $w_i = ε_x²/ε_i²$ (3), with $ε_x² = (Σ 1/ε_i²)⁻¹$ (4), where $ε_i²$ is an exponential average (7) of the squared prediction error estimate $ε̂_i = |x̂_i − x_i| + K_i$ (5), the bias $K_i = 2ε_x²/√(2πε_i²)$ (6) making up for each clock being part of the scale. Each clock's frequency is filtered (9) with its own constant from its τ_min (10).

  • :at2, AT1 plus a frequency variance (Weiss and Weissert, 1991): the weights are AT1's, and each clock's frequency $y$ is a Kalman filter on its average frequency $ŷ$ (8): the variance $P$ grows by the random-walk FM impulse $σ_β²τ$ (13), then $y ← (σ_α² y + P̂ ŷ)/(σ_α² + P̂)$ (14) and $P ← σ_α² P̂/(σ_α² + P̂)$ (15), with the white FM $σ_α² = ε_i²/τ²$ from the prediction error, so the filter adapts as $ε_i$ does. $σ_β²τ$ is fixed per clock from its τmin by the steady state ``m(m+1) = σα²/(σβ²τ)$(18), the starting$σα²$being the starting variance, and$P`starts at its steady state (16). In steady state this is AT1's filter (17). Withsteps=true` the paper's frequency-step detection (19–22) runs too, see below. Takes the AT1 keywords.

  • :greenhall, Greenhall's Kalman timescale (Greenhall, 2003; Greenhall, 2006): one Kalman filter over every clock's phase and frequency (and drift), with one ClockModel per clock in models, whose R is the clock's white PM against the reference. After each update the phase part of the covariance is reduced about the implicit ensemble mean, a weighted mean of the corrected clocks; this keeps the frequency estimates and minimizes each step of the scale, so the scale is quiet at short τ as well as long. The weights are those of that mean. The scale's frequency against the reference settles at a constant set by the start, which comes from a line through each clock's first samples (Greenhall, 2007). With every R = 0 this is the reduced Kalman timescale of the 2003 paper; with R > 0 it is IEMx (2006), the same filter. Readings with noise leave the corrected clocks unequal and the implicit ensemble mean unobservable, so the scale is realized at clock pivot (default 1; the first clock read when it has no reading): that clock's reading less its estimated offset from the implicit mean. It carries that clock's own reading noise as white PM, so it is not quieter than a weighted readout (three equal clocks: √3 noisier at short τ), and pivots differ by that noise; at R = 0 every pivot gives the same scale. While the pivot has no reading the first clock read stands in; a pivot that starts late steps the scale at its first reading. Models with flicker FM states bring them into the filter: at R = 0 that is the algorithm of (Davis et al., 2005) (its eqs 3.1–3.6 and 4.1), and with R > 0 the 2006 paper's reduction covers the same state (its §2: states that reach the readings only through the phases). The frequency reported for a clock then includes them. Flicker PM states are measurement noise with memory: they enter the readings, not the phases the scale is formed from, and move the weights little (strong flicker PM on a clock's readings costs it about a tenth of its weight). That is outside the 2006 paper, whose measurement noise is white; the reduction only needs the readings to be differences of clocks, which they still are.

  • :jones_tryon, the natural Jones–Tryon timescale (Jones and Tryon, 1983; Greenhall, 2003): the same filter as :greenhall without the covariance reduction. The scale is a clock's reading less its estimated phase (JT83 §4, after eq. 4.17; Greenhall 2003 eq. 10); with noiseless readings it is the same at every clock. The frequency estimates are the same as :greenhall's; the scale is slightly noisier at short τ (the reduction is what minimizes its steps: about 4% at τ = 1 on four white-FM clocks, ten seeds, with single records up to 40% higher). Its weights are NaN: no weighted mean defines it. R is the white PM of a clock's reading against the reference, so every difference carries the reference's noise (correlated), where JT83 takes independent errors in each difference. JT83's error detection, step corrections and drift state are not part of it.

  • :stein, Stein's Kalman timescale (Stein, 2003), the KAS-2 algorithm (Levine, 2012; Erickson et al., 2011), with one ClockModel per clock in models. Each clock has phase, frequency and aging states (no aging when no model has q3 > 0) driven by independent shocks of variance q1 τ, q2 τ and q3 τ; R is the clock's reading noise. The clocks are differenced against clock pivot and each difference gets its own Kalman filter (Stein 2003 eq. 5.8). The pivot's own shocks against the ensemble follow from the constraints that the weighted shocks of all the clocks sum to zero (4.1, 7.1), one set of weights for each state, and the other clocks are the pivot plus their difference estimates (6.3, 7.3). The weights are inversely proportional to the variance of the matching noise (Levine §XVI; a clock with no such noise takes all of it); wmax caps them as in KAS-2. The weights returned are the phase weights. The scale is realized at the pivot as for :greenhall. Departures from the paper: the shock variances are qτ (no cross terms between the states, as in the paper's shock model, where :greenhall integrates them), a clock without a reading in a step is predicted from its difference state and the weights run over the clocks read, and the paper's independent difference filters ignore the correlation of their innovations through the pivot, so the scale differs a little with the pivot. With white FM clocks it matches :greenhall to a few percent at every τ.

AT1 keywords:

  • tau_min: each clock's τ_min in seconds, a number or one per clock; the paper takes it from the clock's characterization. Default: the lag of the smallest ADEV of each clock, estimated from the record (the reference's share taken out).
  • memory: the time constant of the variance average in seconds, the paper's $N_τ$ (20 days for cesium clocks, and the default; at most a quarter of the record).
  • bias: :paper (default) for $K_i$ above, or :exact for the squared error divided by $1 − w_i$, which is exact when the clocks' own errors are independent and the weights optimal.
  • steps (:at2, default false): detect a clock's frequency step and rerun the scale without it, in one of two modes. :best (true) replaces the scale from the step on, the best estimate of a recorded history. :real keeps every value already issued, as the paper does (it cannot change history and steers forward): the rerun only corrects what follows, continuing from the last issued phase, so a step costs the samples before it was caught. After each sample, for windows of 2 to lmax − 1 intervals (lmax defaults to the clock's τmin in samples, at least 4), the clock's mean frequency against the scale over the window is compared with its frequency estimate before the window (eqs 19–20). A difference above `stepthreshold(default 5) standard deviations is a step at the window's start: the scale is rerun from there with that clock's weight zero until τ_min later and its frequency variance raised, and it comes back withε_i²multiplied bystepinflate` (default 4, σα doubled), the paper's "increased by a fixed amount". While it is out the clock is still read against the scale, and its frequency and $ε_i²$ go on being estimated (the bias $K_i$ is zero, as its weight is), so that it comes back with its new frequency. Departures: eq 20 as printed mixes units (τmin/L is a time), so the deviation is the variance of the difference, in fractional frequency squared, ``P{−L} + (σ{α,i}² + σ{αx}²)/s + (σ{β,i}²τ + σ{βx}²τ)(s+1)(2s+1)/(6s)$for a window of$s$intervals: the estimate's variance, the white FM of the mean over the window (clock and scale, eq 21), and the frequency random walk over it (the mean of a random walk of impulse σ_β²τ per interval over$s$intervals has variance σ_β²τ (s+1)(2s+1)/(6s), about s/3; scale term as eq 22). The paper's$(P{-L}+P{-2})/2$is$P{-L}`` alone here, and windows start at two intervals, my reading of its two-back start (one interval would flag more small phase jumps; a large lone jump is still flagged). The clock-minus-scale variance is less than the sum of the two when the clock is in the scale, so the sum is conservative, as in the paper. A clock is not tested over windows that reach into its exclusion. The paper's constant is 4, which gives about one false step per 3×10⁴ clock-samples on the noisier clocks of a step-free ensemble (53 in 24 runs of four clocks and 16384 samples, none at 5 or 6); a false step excludes the clock for its τmin and raises its ε², which shifts the weights for good. At 5, in simulation (20 records, the step on a clock of white FM 1.4×10⁻¹¹ per interval among four of 1.0 to 2.8×10⁻¹¹), a frequency step of 5×10⁻¹¹ is caught after 3 to 11 samples, one of 2×10⁻¹¹ after 24 to 82 in 18 of the records, and one of 10⁻¹¹ in 6 of them, after 63 or more. A step of up to about ten times the white FM per interval is learned while the clock is out (five clocks of 10⁻¹² per interval, τmin of 40 intervals, medians of 20 records: 0.98 and 0.97 of steps of 3×10⁻¹² and 10⁻¹¹ at the return). A larger one raises ``εi²`at its first sample, so the filter follows it slowly (0.45 of 3×10⁻¹¹ and 0.05 of 10⁻¹⁰ at the return): the clock comes back with a weight near zero, is taken out once more, and holds 0.98 of the step at its second return. Passstep_threshold=4` for the paper's value.
  • wmax (default 1, no cap): the largest weight any clock may have.
  • outlier (default Inf, off): a clock whose prediction error passes outlier ε_i is left out of that sample and of its variance; if that would leave none, all stay.

The weights are optimal for the interval of the readings: ε_i² is the clock's prediction error over one interval, so for τ well beyond it, and with clocks of different long-term behaviour, the scale can be worse than the best clock. With two clocks the comparisons alone cannot tell which is better, and the weights wander toward either; cap them with wmax or use EWFA. The frequency drift term of the paper's prediction (1) is not used.

SigmaTau.TimescaleResult — Type
TimescaleResult

Output of timescale.

  • algorithm::Symbol: Algorithm that formed the scale (:ewfa, :at1, :at2, :greenhall, :jones_tryon, :stein).

  • comparisons::ClockComparisons: The clocks the scale was formed from.

  • t::Vector{Float64}: Sample times in seconds from the first sample.

  • x::Matrix{Float64}: Each clock minus the scale (s), one column per clock.

  • y::Matrix{Float64}: Each clock's frequency against the scale, as the algorithm estimated it.

  • weights::Matrix{Float64}: Weight of each clock at each sample (rows sum to 1).

  • error::Matrix{Float64}: Each clock's prediction error (s); NaN where it had no reading.

  • xhat::Matrix{Float64}: Each clock's phase against the scale as the algorithm estimated it (s): the filter's phase state for :greenhall, :jones_tryon and :stein, where x is read at the pivot; x itself for the others.

SigmaTau.timescale_phase — Function
timescale_phase(r::TimescaleResult) → PhaseData

The scale against the comparisons' reference: reference − clock i plus clock i − scale, the same for every clock read at that sample (NaN where none was). Its stability is the scale's, as far as the reference is better than it; against an ideal reference (as from simulate_ensemble with reference = 0) it is exact.

SigmaTau.implicit_mean — Function
implicit_mean(r::TimescaleResult, truth) → PhaseData

The implicit ensemble mean of a :greenhall scale against true time, in simulation.

\[\bar x_0 = \sum_i a_i\,(x_i - \hat x_i)\]

It is the weighted mean of the corrected clocks, each clock's true phase $x_i$ less the filter's estimate $\hat x_i$ (r.xhat), with the weights $a_i$ of r (Greenhall (2006), Eqs. (3.8) and (3.13)). truth is the states from simulate_ensemble (truth[k, 1, i] is clock i's phase against true time). The mean carries no clock's reading noise, so its stability is the scale's own. The readout timescale_phase at a pivot clock adds that clock's reading noise; with every R = 0 and every clock read, the corrected clocks agree and the readout is the mean with its sign reversed (timescale_phase is reference − scale). Only for :greenhall, whose weights define the mean.
