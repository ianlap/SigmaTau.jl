Kalman filter

kalman_filter tracks one clock's phase, frequency and, with a drift state, drift through a phase record, on a ClockModel from clock_model. kalman_smooth refines every estimate with the samples after it, holdover_error says how far the model lets the clock wander once the reference is gone (holdover measures it on the record), and innovation_check says whether the model fits the record at all. simulate_clock makes a record with a known truth to try all of this on.

m  = clock_model(powerlaw_fit(p; alphas=[2, 0, -2]))
kf = kalman_filter(p, m)
innovation_check(kf).ok                 # white, unit-variance innovations?
holdover_error(kf, [3600.0, 86400.0])   # 1σ time error after 1 h and 1 day
ks = kalman_smooth(kf)

Gaps (NaN samples) are predicted across without an update. Flicker noise has no state in the model, so on a record dominated by it the innovation check fails. tune_q then retunes the white and random-walk FM levels for the best phase prediction over the horizons you care about, starting from the fit.

t = tune_q(p, m; horizons=[10, 100, 1000])
kalman_filter(p, t.model)
SigmaTau.kalman_filter — Function
kalman_filter(data::PhaseData, m::ClockModel; x0, P0) → KalmanResult

Run the Kalman filter for clock model m over a phase record. The state is phase and frequency, plus drift when m.drift; each sample is a phase reading with white PM variance m.R. NaN samples are gaps: the filter predicts across them without an update.

The start x0, P0 defaults to a least-squares polynomial through the first samples, with its covariance inflated tenfold. The covariance update uses the Joseph form, which keeps P symmetric and positive under round-off.

Pass the result to kalman_smooth, holdover_error or innovation_check.

Examples

using SigmaTau
p = noise_gen(PhaseData, 4096, 1.0; h = Dict(2 => 1e-22, 0 => 1e-24, -2 => 1e-30))
m = clock_model(powerlaw_fit(p; alphas = [2, 0, -2]))
kf = kalman_filter(p, m)
kf.x[end, 2]               # frequency estimate at the last sample
holdover_error(kf, [60.0, 3600.0])

SigmaTau.KalmanResult — Type
KalmanResult

Output of kalman_filter or kalman_smooth: the state estimate at every sample, its covariance, and the innovations.

  • model::ClockModel: Clock model the filter ran on.

  • t::Vector{Float64}: Sample times in seconds from the first sample.

  • x::Matrix{Float64}: State estimates, one row per sample: phase (s), frequency, and drift (1/s) with a drift state.

  • P::Array{Float64, 3}: State covariances, P[:, :, k] at sample k.

  • innovation::Vector{Float64}: Innovations z − H x̂⁻ (s); NaN at gaps.

  • innovation_var::Vector{Float64}: Innovation variances H P⁻ Hᵀ + R (s²); NaN at gaps.

  • smoothed::Bool: Whether x and P are smoothed.

  • xpred::Matrix{Float64}

  • Ppred::Array{Float64, 3}

SigmaTau.kalman_smooth — Function
kalman_smooth(kf::KalmanResult) → KalmanResult

Rauch–Tung–Striebel smoother over a filtered run: each state estimate then uses the whole record, before and after it. The innovations are the filter's.

SigmaTau.holdover_error — Function
holdover_error(kf::KalmanResult, tau) → Vector{Float64}

Standard deviation (s) of the time error after free-running for each τ in tau (seconds) from the last sample, with the filter's last estimate as the starting point: √[Φ(τ) P Φ(τ)ᵀ + Q(τ)]₁₁.

source
SigmaTau.innovation_check — Function
innovation_check(kf::KalmanResult; confidence=0.95) → NamedTuple

Whether the model fits the record, from the normalized innovations eₖ = νₖ/√Sₖ, which are white with unit variance when it does:

  • nis: mean of eₖ², with the χ² interval nis_bounds it falls in at confidence when the model is right. Above the interval, the model's noise is too low; below, too high.
  • acf: lag-1 autocorrelation of eₖ, with acf_bound, the ±bound it stays within for white innovations. Outside it, a noise type is missing or mislevelled.
  • ok: both inside.

SigmaTau.simulate_clock — Function
simulate_clock(m::ClockModel, N; rng=nothing) → (PhaseData, Matrix)

A phase record of N samples from clock model m, and its true states (one row per sample), for checking filters against a known truth. The clock starts at zero phase, frequency and drift.

SigmaTau.prediction_error — Function
prediction_error(kf::KalmanResult, data::PhaseData, horizons; burnin=0) → Vector{Float64}

RMS error (s) of the filter's phase predictions horizons samples ahead: from the estimate at each sample k past burnin, extrapolate the phase to k + h and compare it with the reading there. Gaps are skipped.

source
SigmaTau.tune_q — Function
tune_q(data::PhaseData, m::ClockModel; horizons=[10, 100, 1000], decades=2, points=9, burnin)
    → (model, q1, q2, cost)

Retune the white FM and random-walk FM levels of m for prediction: run the filter over a log grid of points values spanning ± decades around m.q1 and m.q2, and keep the pair whose phase predictions horizons samples ahead have the smallest summed log RMS error (see prediction_error). R and q3 stay as they are. The burn-in defaults to a tenth of the record. Returns the tuned model, the grid axes and the cost on the grid (rows q1, columns q2).

A noise fit gives levels that match σ(τ); tuning gives the ones that predict best, which differ when the record has noise the model lacks, such as flicker FM.
