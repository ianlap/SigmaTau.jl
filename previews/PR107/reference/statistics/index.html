Noise and statistics

Synthesize power-law noise, identify it, and compute the EDF, bias factors and confidence intervals that every estimator applies when ci=true. Noise, EDF and confidence explains the method; these functions are the building blocks, for when you need them outside an estimator call.

Noise

SigmaTau.noise_gen — Function
noise_gen(::Type{PhaseData},     N, tau0; sigma1=Dict(), h=Dict()) → PhaseData
noise_gen(::Type{FrequencyData}, N, tau0; sigma1=Dict(), h=Dict()) → FrequencyData

Synthesize a length-N clock record whose fractional-frequency power spectrum is a sum of user-specified power laws S_y(f) = h_α f^α. Returns either a PhaseData (integrated to phase with sample interval tau0) or a FrequencyData (raw y sequence) depending on the first argument.

α index

αNoise typePhase PSD slope
2WHPM, white phaseflat
1FLPM, flicker phase1/f
0WHFM, white frequency1/f²
-1FLFM, flicker frequency1/f³
-2RWFM, random-walk frequency1/f⁴
-3FWFM, flicker-walk frequency1/f⁵
-4RRFM, random-run frequency1/f⁶

Keys are the integer α or the noise-type name (Dict(:WHFM => 1e-12)).

Specifying the mixture

Pass either sigma1 or h (not both):

  • sigma1[α] = σ: target Allan deviation σy(τ=τ₀) of the α-component. Convenient when working from a clock spec sheet that quotes σy(1 s) directly.
  • h[α] = h_α: fractional-frequency PSD coefficient in S_y(f) = h_α f^α. Unambiguous everywhere.

sigma1 components are rescaled so the empirical σy(τ=τ₀) of the drawn realization equals the request exactly. h components are scaled analytically: the Kasdin–Walter filter driven by unit white noise has one-sided PSD 2τ₀ |2 sin(πfτ₀)|^α, which is 2τ₀ (2πτ₀ f)^α at low frequency, so the component is multiplied by `√(hα / (2τ₀ (2πτ₀)^α))` and its spectrum is

S_y(f) = h_α · (sin(π f τ₀) / (π τ₀))^α,

which is h_α f^α up to the sine-versus-linear roll-off near Nyquist. For α ≤ −1 the process is not stationary and this is the spectrum of its differences: the d-th difference of y has spectrum (2 sin(π f τ₀))^(2d) S_y(f). The test suite checks the spectrum, through differences where needed, for every α from +2 to −4. The empirical σ_y(τ₀) of an h component therefore fluctuates with the realization (≈ √(2/N) relative), and for the coloured noises it is not the continuous-time SP1065 value, because a sampled discrete process is not a band-limited continuous one. Components from different α are statistically independent.

Seed the global RNG (Random.seed!) before calling for reproducible output, or pass an AbstractRNG as rng to draw from a specific stream (e.g. for a Monte Carlo with independent per-realization seeds).

Examples

using SigmaTau, Random
Random.seed!(0)

# Composite: WHFM at σ_y(1 s) = 1e-12 plus RWFM at σ_y(1 s) = 1e-14
p = noise_gen(PhaseData, 8192, 1.0; sigma1 = Dict(0 => 1e-12, -2 => 1e-14))

# Same record but as fractional-frequency
y = noise_gen(FrequencyData, 8192, 1.0; sigma1 = Dict(0 => 1e-12, -2 => 1e-14))

# Specify by h_α (here pure WHFM with h_0 = 2e-24 → σ_y(1 s) ≈ 1e-12)
noise_gen(PhaseData, 8192, 1.0; h = Dict(0 => 2e-24))

SigmaTau.identify_noise — Function
identify_noise(x::Vector{Float64}, m_values::Vector{Int}; dmin::Int=0, dmax::Int=2, remove_drift::Bool=true, b1_length::Symbol=:record) → Vector{Symbol}
identify_noise(data::PhaseData, m_values; kwargs...) → Vector{Symbol}
identify_noise(data::FrequencyData, m_values; kwargs...) → Vector{Symbol}

The record forms take the same keywords and accept any integer vector or TauMode for m_values; a FrequencyData record is integrated to phase first. Use dmax=2 for the Allan family and dmax=3 for the Hadamard family, as the deviation functions do.

Identify the dominant power-law noise type at each averaging factor by the lag-1 autocorrelation of the differenced phase, with a B1/R(n) fallback when fewer than NEFF_RELIABLE effective samples remain.

Every entry is one of :WHPM, :FLPM, :WHFM, :FLFM, :RWFM; the function never returns :unknown. Estimates outside α ∈ [-2, 2] are clamped to the nearest end, an averaging factor whose estimate fails takes the type of the successful one nearest to it in log(m), and a record with no usable estimate at all (e.g. constant) is reported as :WHFM.

The full record always passes through a 5σ outlier filter before the per-m loop; that step is unconditional and unrelated to the polynomial detrend below.

remove_drift

When true (default), each decimated-by-m subseries is quadratically detrended before the lag-1 ACF / B1 ratio is computed. Allantools' autocorr_noise_id does the same thing (detrend(x, deg=2) in ci.py) to remove a frequency offset (linear phase ramp) and drift (quadratic phase term) from the slow content of each averaging window.

When false, the per-m polynomial fit is skipped. This matches Stable32's noise-ID convention; use it when you need α values that line up with a Stable32-generated reference fixture point-for-point. (Before 0.6 this keyword was called detrend; detrend=false still works, with a deprecation warning.)

b1_length

Sets the record length N at which the B1 fallback (used when fewer than NEFF_RELIABLE averaged points remain) evaluates the theoretical B1(N, μ) values that separate the noise types.

  • :record (default): the full record's frequency-sample count, as Stable32 does. α values line up with Stable32 point for point.
  • :averaged: the number of m-averaged frequency points the observed B1 is computed from. This is the length the B1 theory describes, and it identifies random-walk FM far more reliably at long τ (in Monte Carlo runs with N = 1024 and m = 40–128, 55–75 % correct instead of 1–4 %), at the cost of somewhat weaker white-FM identification and less agreement with Stable32.

SigmaTau.noise_id_nnls — Function
noise_id_nnls(data::PhaseData [, m_values]; deviation=:mhdev, alphas=…, weights=:edf)
noise_id_nnls(data::FrequencyData [, m_values]; …)

Decompose a record's measured variance profile into nonnegative power-law components. One weighted nonnegative least-squares fit over the whole τ range returns the amplitude of every α in the basis, plus the dominant noise type at each τ.

Returns a NamedTuple:

fieldmeaning
deviationestimator used
tauτ grid actually fitted (s)
varmeasured σ̂²(τ)
fitfitted Σᵢ aᵢ (τ/τ₀)^μᵢ
alphasbasis exponents
noise_types:WHPM, :FLPM, :WHFM, :FLFM, :RWFM, :FWFM, :RRFM per α
amplitudesaᵢ ≥ 0 — the α-component's variance at τ = τ₀
contributionslength(tau) × length(alphas) matrix aᵢ (τ/τ₀)^μᵢ
dominantdominant noise type at each τ
residualweighted sum of squared residuals
weightsweight vector used
Experimental return shape

The set and naming of these fields is experimental and may change in a minor release; amplitudes, alphas and dominant are the stable core.

The fit runs on the raw deviation profile: ci=false and, for MHTOTDEV, correct_bias=false. Both the CI machinery and the total-family bias divisor are functions of identify_noise, so fitting a corrected profile would make the decomposition depend on the classification it is computing.

Basis

The columns are analytic power laws Kᵢ(τ) = (τ/τ₀)^μ(αᵢ), with μ the variance response exponent — μ = -α-1 for the modified family (MDEV/MHDEV/MHTOTDEV) and, for the unmodified family (HDEV), μ = -α-1 for α ≤ 0 with WPM and FPM both collapsing onto μ = -2. The defaults therefore carry α ∈ {2, 1, 0, -1, -2} for :mdev, {2, 0, -1, -2, -3, -4} for :hdev, and {2, 1, 0, -1, -2, -3, -4} for :mhdev and :mhtotdev. The convergence condition per estimator is:

estimatorconverges forreason
:mdevα > -3second-difference kernel
:mhdev, :hdev, :mhtotdevα > -5third-difference kernel (MHTOTDEV's per-window quadratic detrend matches it, so the boundary extension keeps the range)

An unmodified basis additionally cannot carry both PM columns — they are the same column. Passing a basis that violates either rule is an error.

Weights

  • :edf (default) — wₖ = νₖ / (2 σ̂⁴ₖ), the inverse of the χ² sampling variance of a variance estimator with νₖ degrees of freedom. The per-τ noise type that the EDF model needs comes from a first :relative-weighted pass of this same fit, not from identify_noise — the routine is meant to replace that classifier, so it does not lean on it. Points where the EDF model returns a non-finite or non-positive ν fall back to the :relative weight, and α ≤ -3 rows borrow the RWFM EDF (the shipped tables stop at α = -2).
  • :relative — wₖ = 1 / σ̂⁴ₖ, i.e. equal fractional weight per τ.
  • any AbstractVector of per-τ weights.

Caveats

The analytic basis assumes each component is in its asymptotic power-law regime over the whole fitted range. Two things break that:

  • Total estimators. MHTOTDEV's reflected/extended windows bend the response away from τ^μ as τ → T, which distorts the last octaves. An empirical basis (ensemble-mean σ̂²(τ) of synthesized unit noises) avoids this; prefer it, or :mhdev, when the long-τ octaves matter.
  • Flicker PM under an unmodified estimator. The ln(2π f_h τ) factor is absorbed into the α=2 column, so an FPM record fitted with :hdev reports white PM.
  • Small τ. Every estimator is still in transition toward its asymptotic power law at m = 1–2 (the modified family runs 2–3× high there, settling by m ≈ 8), so the default grid starts at m = 4. Fitting the dropped octaves lets a pure WFM record buy off its m = 1 excess with a spurious WPM column.

Amplitudes are variances at τ = τ₀; sqrt.(result.amplitudes) is the corresponding σ_y(τ₀) per component.

Examples

using SigmaTau, Random
Random.seed!(0)

p = noise_gen(PhaseData, 8192, 1.0; sigma1 = Dict(0 => 1e-12, -2 => 1e-14))
r = noise_id_nnls(p)
collect(zip(r.noise_types, r.amplitudes))   # amplitude per α
r.dominant                                  # dominant type per τ

See also identify_noise for the per-τ lag-1 ACF classifier and noise_gen for the matching synthesizer.

EDF, bias and confidence intervals

SigmaTau.DEFAULT_CONFIDENCE — Constant

Default confidence level (0.683, one sigma, the Stable32 convention) for every deviation with a χ² confidence model. Override per call with confidence=0.95. mtie and tierms have no interval model and ignore it.

SigmaTau.calculate_edf — Function
calculate_edf(method::Symbol, devs::Vector{Float64}, noises::Vector{Symbol}, m_values::Vector{Int}, taus::Vector{Float64}, N::Int, T::Float64) → Vector{Float64}

Equivalent degrees of freedom for the chosen method. Uses the Greenhall–Riley spectral integrals for ADEV / MDEV / HDEV / MHDEV (via _calc_edf_core), the published EDF coefficient tables for the total-family estimators, and the SP1065 Table 3 empirical formulas for :theo1 (via _theo1_edf).

WHPM/FLPM fallback for TOTDEV and HTOTDEV: NIST SP1065 Table 9 and FCS 2001 publish coefficients for α ∈ {0, -1, -2} only. For α ∈ {1, 2} this routine falls back to the ADEV-style (d=2, F=m, S=m) or HDEV-style (d=3, F=m, S=m) Greenhall–Riley formula so every noise type yields a finite EDF instead of NaN. S=m matches the overlapped convention applied to the four overlapped variants (ADEV/MDEV/HDEV/MHDEV); both TOTDEV and HTOTDEV operate on a stride-1 phase record (Howe's reflected-boundary extension preserves overlap), so the overlapped EDF is the consistent choice. The substitute is pragmatic, not canonical: it is dominated by the same noise-shape contribution as ADEV/HDEV at WHPM/FLPM, but is documented as a policy choice rather than a derivation.

SigmaTau.bias_correction — Function
bias_correction(noises::Vector{Symbol}, var_type::Symbol, taus::Vector{Float64}, T::Float64) → Vector{Float64}

Variance-scale bias factor B(α) = E[estimator²] / true_variance in the SP1065 / FCS 2001 convention. Apply as σ_unbiased = σ_raw / √B, i.e., the caller takes the square root before dividing the deviation.

  • B < 1 → estimator biased low (raw σ understates the truth).
  • B > 1 → estimator biased high (raw σ overstates the truth).

Recognised var_type values: :totvar, :mtot, :htot, :mhtot.

Conventions per variance type:

  • :totvar: Howe/Walter (1994). B = 1 − a·τ/T with a = 1/(3·ln 2) for FLFM, a = 0.75 for RWFM, zero elsewhere. Biased low for the divergent FM noises only.
  • :mtot: SP1065 Table 11 / Greenhall 1999. Independent of τ. Biased high (B > 1); MTOT overstates MVAR, consistent with the Monte Carlo of Howe & Vernotte 2003 (Table 1). Stable32 reports MTOT raw, so correct_bias=false on mtotdev matches Stable32.
  • :htot: FCS 2001 (Howe & Tasset) Table I a column. B = 1 + a with the published a ∈ {-0.005, -0.149, -0.229, -0.283, -0.321} for α ∈ {0, -1, -2, -3, -4}. Biased low (B < 1); HTOT understates the divergent-FM variance. B = 1 for α > 0 (no published model; matches Stable32).
  • :mhtot: measured by Monte Carlo (tools/mc_mhtotdev.jl) over the τ/τ0 ≥ 16 validity window, since MHTOTDEV is novel to SigmaTau and no external reference exists. Modeled τ/T-linearly, B = b0 + b1·(τ/T) (like :totvar): b0 ∈ {0.901, 0.824, 0.793, 0.784, 0.788} and b1 ∈ {-0.008, -0.054, -0.042, -0.036, -0.032} for α ∈ {2, 1, 0, -1, -2}. MHTOTDEV reads low (B ≈ 0.9 for WHPM, ≈ 0.79 for the FM noises) because each window's quadratic detrend absorbs part of its variance. See docs mhtotdev.md.

Anything unrecognised falls through to B = 1.
