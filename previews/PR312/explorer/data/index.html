Data

The Data page holds the record: where it comes from, how it was read, what is in it and what is done to it before every analysis. With several clocks it shows one of them, the one clicked in the list of clocks.

Opening a file

Open a file… opens a text file of readings, and a file dropped anywhere in the window opens the same way. Once a file is loaded the card shows its name and how it was read, with three buttons:

ButtonAction
Import settings…Opens the import dialog again for this file
Open another file…Puts another file in the place of this clock
+ Add clockOpens a file as a further clock and keeps those loaded

The explorer reads the files that read_data reads:

  • text in columns, separated by blanks, commas or tabs, with NaN for a missing sample. Lines that start with # are skipped, and a first line of names is taken as the names of the columns;
  • Stable32 phase and frequency files (.phd, .frd) and TimeLab files (.tim), with the sample interval from their headers;
  • the readings of a counter, one per line in the number format of SCPI (+9.999999999E+06): frequencies in hertz become fractional frequency, and time intervals become phase;
  • tables with named columns and ISO 8601 timestamps;
  • the BIPM files of UTC − UTC(k);
  • RINEX clock files (.clk), from which the clocks are chosen in a list.

A file compressed with gzip (.gz) is unpacked as it is opened.

The import dialog

The dialog shows the top of the file and what the explorer proposes to read from it. The proposal comes from the names of the columns, the header and the size of the values. Check it before loading, the record type above all.

The heading of each column is a menu:

ChoiceThe column holds
IgnoreNothing to read
Time (s), Time (days, MJD), Time (h), Time (min)The time of each reading, in that unit
ClockThe readings of one clock

Every column marked Clock becomes a clock, all measured against the same reference at the same instants. A click on the name of a column adds it as a clock or drops it.

SettingMeaning
Record typePhase (time error) or Fractional frequency
Phase units, Frequency unitsSeconds to picoseconds for phase, and fractional, ppm, ppb or ppt for frequency. The field below takes a factor instead, written as an expression of numbers, pi, + - * / and parentheses, such as 1/(2*pi*5e14) for the phase of an optical carrier in radians
Sample interval τ₀The step of the time column, or the interval that the header states. Without either it has to be typed
Measured againstThe name of the reference, shown beside As measured in the list of clocks
Clock name, Clock namesThe name of each clock on the plots and in the exports
Remember for files like thisReads the next file with the same extension, number of columns and column names without the dialog

When the time column skips readings, the dialog counts the gaps and the missing samples. They enter the record as missing samples.

In a Stable32 file (.phd, .frd) a zero marks a missing sample, except the first and the last sample of a phase file. The dialog counts these zeros and reads them as missing samples. Keep zeros as readings reads them as samples, for a record whose zeros are readings, as quantized data can have.

A file that is read with remembered settings says so in the status bar. A Stable32 file with zeros opens the dialog all the same, unless the remembered settings keep them. Import settings… on the Data page opens the dialog for it. Files of different kinds that share an extension and a layout share the remembered settings too, so check the line under the file name.

Simulated records

Synthesize makes a record in place of a file, from the number of samples, the sample interval and a seed. Its noise is white FM with a random walk of the frequency, of $10^{-12}$ and $10^{-14}$ per sample as standard deviations. The same seed gives the same record.

FieldRange
Clocks1 to 8
Samples64 to 10,000,000
τ₀ (s)The sample interval
SeedA whole number

With several clocks, each is noisier than the one before by a factor of two in deviation, and all are simulated against one ideal reference. The Ensemble page forms its time scale from them. The Synthesis page simulates clocks from a noise model of your own.

The record check

The record check is computed when the record is read and again whenever its preparation changes. It describes the record as prepared.

LineMeaning
SamplesThe number of phase samples, with the missing ones. A frequency record of $N$ readings has $N + 1$
SpanThe number of samples times the sample interval
StartThe time of the first sample in UTC, for a file with timestamps
GapsThe number of missing samples
Points past 5σThe outliers that find_outliers finds: frequency samples more than five scaled median absolute deviations from the median. They are marked on the phase plot
Frequency driftThe slope of a least-squares line through the fractional frequency, per day. It reads Drift left after a quadratic removal

Preparing the record

Three steps are applied before every analysis, the check and the plots included. Gaps, outliers and drift says when each is called for.

Drift removal fits the phase by least squares over the samples that are not missing and removes the fit. Linear removes a line, which takes out a frequency offset. Quadratic removes a parabola, which takes out a linear frequency drift as well. The check then lists the offset and the drift that were removed.

Fill gaps by reflection fills the missing samples as fillgaps does, from the samples beside each gap, reflected into it. The missing samples are the readings that the time column skips, those written as NaN and the zeros of a Stable32 file that are read as missing. For a frequency record that has any of them it is on from the start, since a frequency record cannot be read with samples missing.

remove, beside the count of outliers, replaces them as remove_outliers does. The missing samples of the record stay missing. undo brings the outliers back.

Records with gaps

A phase record with missing samples is analyzed as it is by the estimators that leave them out (Estimators and noise types). An estimator that needs a complete record stops the run with an error, and the Spectrum page has no spectrum for the record. A frequency record with missing samples cannot be read while Fill gaps by reflection is off, and the record check then keeps that box alone, to turn the filling back on.

The phase plot and the analysis range

The Phase view plots the phase of the record as prepared, with the outliers marked. A drag zooms, and a double click restores the full range. The curve breaks where samples are missing. A record of more than 4000 samples is cut into 1332 stretches, and the curve runs through the lowest and the highest sample of each and through the two ends of the record, so that it keeps every outlying sample.

Select range turns the drag into a choice of the part of the record to analyze. The range is shaded, and the line above the plot gives its limits. It needs at least 16 samples. The Stability, Spectrum, Dynamic, Holdover and Steering pages then use that part alone, with the drift removal fitted to it. The check and the plot keep the whole record. whole record clears the range. Each clock has its own.

Frequency drift

The Frequency drift view plots the fractional frequency of the record as prepared and fits one of four models to it by least squares, as drift_fit does:

ModelFrequency
Linear$a + b\,t$
Quadratic$a + b\,t + c\,t^2$
Log$a \ln(1 + b\,t) + c$
Diffusion$a + b\sqrt{t + c}$

The line above the plot gives the drift rate at the end of the record, per day, with its standard error and the rms of the residuals. Hovering over it shows the coefficients. Residuals plots what the model leaves.

The standard error assumes white residuals. It is too small where they are not white, as on a record with flicker or random-walk FM.

To fit the drift of the record as measured, set Drift removal to None: the view shows the frequency after the removal.
