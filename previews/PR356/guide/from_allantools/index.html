Coming from allantools

allantools and this package compute the same estimators from the same definitions, and on the same record their uncorrected deviations agree to eight digits or more (Related software). They differ in what a call takes and returns, in a few names, and in what is applied to a result by default. This page maps allantools 2024.6 onto this package, in Python and in Julia.

The call

An allantools function takes an array, a sample rate and averaging times in seconds, and returns four arrays. Here a function takes a record, which carries its sample interval, and averaging factors $m$, and returns one result:

import allantools
taus, dev, err, n = allantools.oadev(x, rate=10.0, data_type="phase", taus=[1.0, 10.0])

import sigmatau as st
r = st.adev(st.PhaseData(x, 0.1), [10, 100])
r.tau, r.dev, r.noise_type, r.ci_lower, r.ci_upper, r.edf, r.neff
using SigmaTau
r = adev(PhaseData(x, 0.1), [10, 100])

allantools rounds each requested time to a multiple of $τ_0$ and leaves out the ones the record cannot support. This package keeps a row for every factor asked for, with NaN where the record is too short.

Names

The plain adev and hdev of allantools are the non-overlapping estimators. Here the plain names are the overlapping ones, which the standard recommends over them for their better confidence (IEEE Std 1139-2022, A.3.2).

Three of these return more here. cross_adev keeps the sign of the covariance, of which gcodev returns the square root of the magnitude. ncornered_hat returns all the clocks, with an interval for each and NaN where an estimate is negative. three_cornered_hat_phase returns the first clock and sets a negative variance to zero.

With correct_bias = false the deviations are those of allantools. Validation compares the two at every averaging time of a reference record, and a job of the test suite repeats the comparison with allantools 2024.6 on every change.

Not in this package

  • psd2allan, which integrates a tabulated spectrum to an Allan or modified Allan deviation. powerlaw_sigma gives the deviations of a power-law model.
  • phase2radians and frequency2fractional. read_data converts counter readings in hertz to fractional frequency as it reads them.

Not in allantools

The modified Hadamard and Hadamard time deviations (mhdev, htdev), the modified Hadamard total deviation (mhtotdev), ThêoH (theoh), the dynamic deviations (dadev, dhdev), bias correction of the total deviations, drift fits, readers for instrument files, and the clock model with its Kalman filter and time scales. The home page has the whole list.

Reading a file

allantools takes arrays that you load yourself. This package reads text columns, Stable32 and TimeLab files and counter logs, with their sample interval and their gaps:

p = st.read_data("clock.dat")

Reading and saving data covers the formats, and Python the rest of the Python interface.
