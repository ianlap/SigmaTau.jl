Using the explorer

Load a record on Data, pick estimators in the panel, and press Run analysis. Add more clocks to compare them: colour then means clock and line style means estimator.

  • F5 run the analysis
  • 1–4 switch pages
  • Hover a point for its value, drag to zoom, double-click to reset.
