Suites, τ grids and streaming

Several estimators at once

SigmaTau.stability — Function
stability(data::PhaseData; devs=DEFAULT_DEVIATIONS, m=Octave,
          ci=true, confidence=DEFAULT_CONFIDENCE, correct_bias=true,
          remove_drift=true) → StabilitySuite

Compute a suite of stability deviations from one record in a single call, the batch analog of adev, mdev, …. Each symbol in devs is run through deviation with a per-deviation averaging-factor grid derived from m, so every deviation gets a grid valid for its own algorithmic m-max. Returns a StabilitySuite. Also accepts FrequencyData.

devs is any iterable of estimator names from estimators (symbols or strings). m is a TauMode (e.g. Octave, Decade) or an integer vector of averaging factors applied to every deviation, as in the estimator functions. correct_bias reaches only the estimators that take it (the total family and theo1), and remove_drift only mhtotdev. Note that an explicit m vector is passed to every deviation verbatim: :theo1 interprets it as even Thêo1 factors (odd entries give NaN rows) and :theoh as τ-grid factors, so prefer a TauMode when mixing the Theo family with others.

Examples

julia> using SigmaTau

julia> pd = PhaseData(collect(1.0:64.0), 1.0);

julia> suite = stability(pd; devs=(:adev, :hdev), m=Octave, ci=false);

julia> keys(suite)
2-element Vector{Symbol}:
 :adev
 :hdev

julia> suite[:adev].deviation_type
:adev
source
SigmaTau.DEFAULT_DEVIATIONS — Constant

Default deviation set computed by stability when devs is not given: overlapping Allan, modified Allan, overlapping Hadamard, and modified Hadamard. All four are fractional-frequency (σy) quantities, so the default suite overlays on one ordinate; time deviations (tdev, htdev) are σx quantities in seconds and must be requested explicitly.

Estimators by name

estimators describes every estimator (name, label, family, axis, whether it takes correct_bias, a one-line description), and deviation runs one chosen by its name. The explorer and the command-line tool use both, so they list the same estimators as the library.

SigmaTau.estimators — Function
estimators() → Vector{NamedTuple}

The estimators deviation and stability know, one entry per estimator with fields

  • name::Symbol: the function name, e.g. :adev;
  • label::String: the display name, e.g. "ADEV";
  • family::Symbol: :allan, :total, :theo or :time;
  • axis::Symbol: :sigma_y (fractional frequency) or :sigma_x (seconds);
  • correct_bias::Bool: whether the correct_bias keyword applies;
  • description::String: one line for menus and help.

The dynamic deviations dadev / dhdev return maps, not σ(τ) curves, and are not listed.

Examples

julia> using SigmaTau

julia> e = estimators(); e[1]
(name = :adev, label = "ADEV", family = :allan, axis = :sigma_y, correct_bias = false, description = "Overlapping Allan deviation, the standard")

julia> [x.name for x in e if x.axis === :sigma_x]
5-element Vector{Symbol}:
 :tdev
 :htdev
 :ttotdev
 :mtie
 :tierms

SigmaTau.deviation — Function
deviation(name::Symbol, data, m=Octave; ci=true, confidence=DEFAULT_CONFIDENCE,
          correct_bias=true, remove_drift=true) → StabilityResult

Run the estimator called name (any name from estimators) on a PhaseData or FrequencyData record. m is a TauMode, resolved against the estimator's own m-max, or any integer vector of averaging factors. correct_bias is passed only to the estimators that take it (the total family and theo1) and remove_drift only to mhtotdev; mtie and tierms accept ci and confidence but report no intervals.

deviation(:adev, pd, m) is adev(pd, m); use it when the estimator is chosen at run time (a menu, a command-line flag, a loop). It is written as plain branches, so it compiles under juliac --trim.

Examples

julia> using SigmaTau

julia> pd = PhaseData(collect(1.0:64.0) .^ 2, 1.0);

julia> deviation(:hdev, pd, 1:3; ci=false).dev == hdev(pd, 1:3; ci=false).dev
true

τ grids

SigmaTau.TauMode — Type
TauMode

Selector for the averaging-factor grid used by the public deviation API and stability. Pass an instance in place of an explicit m_values vector, e.g. adev(pd, Octave).

Instances:

TauModeSpacingExample grid (large m_max)
AllTausevery integer1, 2, 3, 4, 5, …
Octavefactor 21, 2, 4, 8, 16, …
HalfOctavefactor √21, 2, 3, 4, 6, 8, 11, 16, …
QuarterOctavefactor 2^(1/4)1, 2, 3, 4, 5, 6, 7, 8, 10, …
Decadefactor 101, 10, 100, 1000, …
HalfDecadefactor √101, 3, 10, 32, 100, …

Octave is the package default and reproduces the grid that the zero-arg convenience methods (adev(pd), …) have always used. Grids are rounded to integers, deduplicated, and clamped to each kernel's algorithmic m-max (see tau_values).

source
SigmaTau.tau_mode — Function
tau_mode(s::AbstractString) → TauMode

Parse a τ-grid name, as typed on a command line or chosen in a menu, into a TauMode. Case and the separator are ignored, so "half-octave", "half_octave", "halfoctave" and "HalfOctave" all give HalfOctave; "all" and "alltaus" give AllTaus.

Examples

julia> using SigmaTau

julia> tau_mode("half-decade")

SigmaTau.tau_values — Function
tau_values(mode::TauMode, N::Int, kernel::Symbol) → Vector{Int}

Averaging factors m (with τ = m·τ₀) for the grid mode, bounded above by kernel's algorithmic m-max for an N-sample record. The return value is the same Vector{Int} accepted by the explicit m_values form of every deviation (e.g. adev(pd, tau_values(Decade, length(pd.x), :adev))), and the deviation functions accept a TauMode directly (adev(pd, Decade)) as shorthand.

Note the name reads like seconds, but the returned values are averaging factors, matching the existing m_values convention. kernel is the deviation symbol (:adev, :mdev, …) that determines the m-max clamp; see _kernel_m_max.

For :theo1 (defined at even averaging factors only, SP1065 eq. 30) odd grid entries are rounded up to the next even value, deduplicated, and clamped to the even m-max. :theoh grids are plain integers: its m-values are τ-grid factors (target τ = m·τ0) and the even-factor conversion for the Thêo1 segment happens inside theoh.

tau_values(Octave, N, kernel) equals _default_m_values(N, kernel).

source

The exported TauMode instances are AllTaus, Octave, HalfOctave, QuarterOctave, Decade and HalfDecade.

Streaming

StreamingStability computes adev, mdev, hdev or mhdev as phase samples arrive, at O(1) cost per sample per averaging factor. At every sample count the streamed estimate equals the batch call on the samples seen so far.

acc = StreamingStability(:adev, 1.0, [1, 10, 100])
push!(acc, x_next)        # one phase sample
append!(acc, xs)          # a chunk, in order
snapshot(acc)             # StabilityResult over everything seen so far
nsamples(acc)             # samples streamed so far
SigmaTau.StreamingStability — Type
StreamingStability(dev::Symbol, tau0, m_values)

Real-time streaming accumulator for the overlapping difference-family deviations: feed phase samples one at a time with push! (or in chunks with append!) and read off the running deviation estimate at any moment with snapshot, without storing the record or recomputing anything.

dev selects the estimator: :adev, :mdev, :hdev, or :mhdev. tau0 is the sample interval in seconds and m_values the averaging factors (τ = m·τ₀), exactly as in the batch API. At every sample count the streamed estimate equals the corresponding batch call on the samples seen so far (adev(PhaseData(x[1:k], tau0), m_values; ci=false), etc.).

Implements the running-sum scheme of Dobrogowski & Kasznia (Dobrogowski and Kasznia, 2007), generalized to third differences for the Hadamard pair. Each sample costs O(length(m_values)), and memory is a ring buffer of at most 4·maximum(m_values) + 1 samples. The total and Thêo families cannot stream: they re-read the whole record.

Example

acc = StreamingStability(:adev, 1.0, [1, 10, 100])
for x in phase_source            # samples arrive one at a time
    push!(acc, x)
end
result = snapshot(acc)            # StabilityResult, same dev values as batch
source
Base.push! — Method
push!(acc::StreamingStability, x_next::Real) → acc

Feed one new phase sample (seconds) into the accumulator. Updates every per-m running sum in O(1) per averaging factor, per the Dobrogowski–Kasznia scheme (Dobrogowski and Kasznia, 2007): the squared-difference sum update of their eq. 9 for :adev (third-difference form for :hdev), the inner-sum build/slide of their eqs. 12–13 plus the overall-sum update of eq. 11 for :mdev (third-difference generalization for :mhdev).

source
Base.append! — Method
append!(acc::StreamingStability, xs::AbstractVector{<:Real}) → acc

Feed a chunk of phase samples (seconds), in order; equivalent to push!-ing them one at a time.

source
SigmaTau.snapshot — Function
snapshot(acc::StreamingStability) → StabilityResult

The deviation estimate over all samples streamed so far, as a plain StabilityResult. dev matches the batch kernel on the same record at every m (NaN where the batch kernel has fewer than 2 analysis windows); neff carries the current window counts (0 at NaN points). The ci/edf/noise_type fields are empty (on-demand EDF/CI for streaming accumulators is not implemented); for confidence intervals run the batch API on the full record.

source

nsamples(acc::StreamingStability) → Int
