Shared types

Core data types used across the package and re-exported from SigmaTau.

Types

SigmaTau.AbstractTimingData — Type
AbstractTimingData

Supertype of timing data records (PhaseData, FrequencyData).

SigmaTau.PhaseData — Type
PhaseData{T<:AbstractFloat}

Phase residuals x(t) sampled at uniform interval tau0 (default 1.0 s).

  • x::Vector{T} where T<:AbstractFloat: Phase samples in seconds.

  • tau0::Float64: Base sample interval τ₀ in seconds.

source
SigmaTau.FrequencyData — Type
FrequencyData{T<:AbstractFloat}

Fractional-frequency samples y(t) at uniform interval tau0 (default 1.0 s).

  • y::Vector{T} where T<:AbstractFloat: Fractional-frequency samples (dimensionless).

  • tau0::Float64: Base sample interval τ₀ in seconds.

source
SigmaTau.StabilityResult — Type
StabilityResult

Unified return type for every stability calculation.

The noise_type, ci_lower, ci_upper, and edf vectors are empty when the calculation was invoked with ci=false.

  • deviation_type::Symbol: Which deviation produced this result (e.g. :adev, :mdev).

  • tau::Vector{Float64}: Analysis intervals τ in seconds.

  • dev::Vector{Float64}: Stability deviation σ_y(τ) per interval.

  • noise_type::Vector{Symbol}: Noise-type symbol identified at each τ (empty unless ci=true).

  • ci_lower::Vector{Float64}: Lower CI bound (empty unless ci=true).

  • ci_upper::Vector{Float64}: Upper CI bound (empty unless ci=true).

  • edf::Vector{Float64}: Equivalent degrees of freedom (empty unless ci=true).

source
SigmaTau.StabilitySuite — Type
StabilitySuite

Ordered collection of StabilityResults computed from one timing record in a single stability call, plus the session metadata needed to reproduce and serialize the analysis.

Index by deviation symbol to recover a result (suite[:adev]) or by position (suite[1]). The suite is iterable in request order and supports keys, haskey, length, and pairs, so a CLI or GUI can render it as an ordered table.

  • results::Vector{StabilityResult}: Per-deviation results, in the order they were requested.

  • data_kind::Symbol: Input record kind: :phase or :frequency.

  • tau0::Float64: Base sample interval τ₀ in seconds.

  • n::Int64: Number of input samples N.

  • confidence::Float64: Confidence level used for the CI bounds (NaN when ci=false).

  • tau_mode::Symbol: Tau-grid selector, recorded as a Symbol (e.g. :Octave, or :explicit).

source
SigmaTau.SpectralResult — Type
SpectralResult

Unified return type for every spectral-density estimate (Sy, Sx, L).

Mirrors StabilityResult: a flat, non-parametric record carrying the one-sided frequency grid, the estimated spectrum, and the Welch parameters that produced it, so a saved or plotted result is self-describing.

  • spectral_type::Symbol: Which estimate produced this result: :Sy, :Sx, or :L.

  • freq::Vector{Float64}: One-sided frequency grid f in Hz.

  • psd::Vector{Float64}: Spectral density at each f; interpret per units.

  • units::Symbol: Units of psd: :per_Hz (Sy, 1/Hz), `:s2perHz` (Sx, s²/Hz), or :dBc_per_Hz (ℒ(f)).

  • nperseg::Int64: Welch segment length (samples).

  • noverlap::Int64: Welch segment overlap (samples).

  • window::Symbol: Window applied to each segment: :hann, :hamming, or :rectangular.

source

Tables.jl

StabilityResult and StabilitySuite implement the Tables.jl row-table interface when Tables is loaded:

using SigmaTau, Tables

rows = Tables.rows(adev(data; ci=true))
cols = Tables.columntable(stability(data; devs=(:adev, :mdev)))

The extension is optional. Tables is a weak dependency, so loading SigmaTau alone does not load the wider tabular-data stack. Empty confidence fields from ci=false are exposed as missing table values.
