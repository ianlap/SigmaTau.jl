Exports, sessions and reports

The File menu saves the plots on screen, the numbers of the last run, a report of the analysis and the whole session. In a browser each file is a download. The desktop app asks where to save it.

EntryFileHolds
Plot as PNGsigmatau-<page>.pngThe plots of the page, at twice their size on screen
Plot as SVGsigmatau-<page>.svgThe same plots as vector graphics
Results as TSVsigmatau-results.tsvThe deviations of the last run, one line for each averaging time
Results as JSONsigmatau-results.jsonEverything the last run returned
Report (HTML, prints to PDF)sigmatau-report.htmlThe analysis as one page that can be printed
Save session…sigmatau-session.jsonThe clocks, their files and the settings
Open session…Opens a saved session

Plots

The image is the plot as it is on screen, with its zoom and with any pinned runs. In the light theme the margin around the axes is transparent. In the dark theme the image keeps the dark card behind the plot.

On a page with several plots, such as the two spectra of the Spectrum page or the maps of several clocks on the Dynamic page, one image holds every plot that is shown, placed as on screen. In a browser, the camera button that appears on hovering over a plot saves that plot alone as a PNG.

Results

The TSV file is a table for a spreadsheet or a script, with tabs between the columns:

ColumnHolds
clockThe name of the clock
estimatorThe estimator, such as adev
tau_sThe averaging time in seconds
sigmaThe deviation
ci_lo, ci_hiThe limits of the confidence interval. Empty without intervals
edfThe equivalent degrees of freedom
noiseThe noise type under its name in the package, such as WHFM
neffThe number of terms in the estimate

The JSON file is the output of sigmatau analyze for each clock, with the name of the clock added: the record check, the settings of the run, the deviations, the spectra, the noise model and the mask checks. With several clocks it is a list.

Both files hold every clock with results, hidden clocks included.

The report

The report is a single HTML file with its figures inside, which a browser prints to PDF. It records what was analyzed and how:

SectionHolds
AnalysisThe estimators, the τ grid and limits, the confidence level, the bias correction, the noise type and the reference clock
RecordsFor each clock: the file and its SHA-256 hash, the record type, the samples, the sample interval, the span, the gaps, the outliers, the drift and the preparation
StabilityThe plots of the Stability page for the frequency and the time estimators, on a white background
ResultsA table for each clock and estimator: averaging time, deviation, interval, EDF, noise type and number of terms
ReproduceThe sigmatau analyze command of each clock

The report states the settings on screen, so it is refused while the results are out of date: run the analysis first. Hidden clocks are left out.

The commands under Reproduce name each file without its folder and print CSV. Run in the folder of the file with the same version of the program, they return the deviations of the report. The hash identifies the file that was analyzed. A gzip file is named and hashed as unpacked, the form in which the program reads it.

Sessions

Save session… writes one JSON file that holds:

  • every clock, with the content of its file, its import settings, its preparation, its analysis range and its noise model if built by hand;
  • the reference clock;
  • the estimators and options of the side panel;
  • the display settings of the Stability, Spectrum and Dynamic pages and the settings of the Holdover and Steering pages.

It holds no results. Open session…, or the file dropped on the window, puts these clocks and settings in the place of those on screen and runs the analysis. Pinned runs and the settings of the Synthesis, Ensemble and Live pages are not saved.

A session file contains the records themselves. It is as large as they are, and it hands the whole analysis to whoever receives it.
